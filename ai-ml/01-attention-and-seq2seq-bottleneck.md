# 어텐션 메커니즘과 Seq2Seq의 병목 현상

## Seq2Seq의 구조적 한계: 병목 현상(Bottleneck)

기존 Seq2Seq 모델은 입력 문장의 길이와 상관없이, 전체 문맥을 **고정된 크기의 컨텍스트 벡터 하나**에 압축해서 디코더로 전달한다. 문장이 길어지면 이 하나의 벡터에 방대한 정보를 억지로 눌러 담다가 **문장 앞부분의 정보가 유실**되는 구조적 한계가 있는데, 이를 **병목 현상(Bottleneck)** 이라 부른다.

어텐션 메커니즘은 이 병목 현상을 해결하기 위해 등장했다 — 인코더의 마지막 벡터 하나에만 의존하지 않고, **인코더의 모든 시점(단어)의 벡터를 디코더가 필요할 때마다 다시 참고**할 수 있게 만든 것이다.

## 어텐션 연산 2단계: Q, K로 유사도 계산 → Softmax로 정규화

1. **유사도 점수 계산**: 디코더의 현재 상태 벡터(**Q**, Query)와 인코더의 각 단어 벡터(**K**, Key)를 내적(dot product)하여 유사도 점수(Score)를 구한다.
2. **정규화**: 이 점수에 **소프트맥스(Softmax)** 함수를 적용해 총합이 1이 되는 확률 분포(가중치)로 변환한다.

```
Score = Q · K
Attention Weight = softmax(Score)
```

- **왜 소프트맥스인가**: 시그모이드, ReLU, tanh는 각각 이진 분류/은닉층 활성화/범위 압축 등 다른 목적의 활성화 함수이며, "여러 값의 총합을 1로 만드는 정규화" 역할은 하지 못한다. 소프트맥스만이 여러 유사도 점수를 "각 단어에 얼마나 집중할지"를 나타내는 확률 분포로 바꿔준다.
- 이렇게 구한 가중치를 인코더의 각 단어 벡터(**V**, Value)에 곱해서 더하면, 디코더가 현재 시점에 어떤 입력 단어에 더 집중해야 하는지를 반영한 벡터를 얻는다.

## 헷갈렸던 포인트

- "정보 유출"이 아니라 **"병목 현상(Bottleneck)"** 이 정확한 용어다. 정보가 새어나가는(leak) 게 아니라, 압축 과정에서 소실(loss)되는 것이라는 뉘앙스 차이를 기억하기.
- Q·K 내적 → 유사도 점수 → **Softmax** → 가중치, 이 순서를 헷갈리지 않기 (Softmax는 점수를 구한 *다음* 단계).
