# AI를 튜터로 활용하는 워크플로우

부트캠프 초반부터 반복해서 강조된 원칙: **AI를 코드 자동 생성기가 아니라 개인 튜터로 사용한다.**

## 기본 학습 루프

```
보고 실행하기 → 결과 예상하기 → 코드 바꿔 보기 → 다시 실행하기
  → AI에게 질문하기 → 오류 해결하기 → 스스로 작성하기
```

## 이렇게 사용한다 (권장)

- 어려운 개념을 더 쉽게 다시 설명받기
- 오류 메시지를 해석해달라고 요청하기
- 다음 한 단계의 힌트만 받기
- 내가 작성한 코드의 문제점을 검토받기
- 두 코드의 차이를 설명받기
- 테스트해야 할 입력값을 추천받기

## 이렇게 사용하지 않는다 (지양)

- 문제를 읽자마자 완성 코드 전체를 요청하기
- 이해하지 못한 코드를 그대로 복사하기
- 실행하지 않고 AI 답변을 곧바로 정답으로 판단하기
- 예상 결과와 실제 결과를 비교하지 않기

## 프롬프트 예시

**개념을 쉽게 설명받기**

```
저는 파이썬을 처음 배우고 있습니다.
아래 코드를 한 줄씩 설명해주세요.
print("Hello, Python!")

1. print가 무엇인지
2. 괄호는 왜 사용하는지
3. 따옴표 안의 내용은 무엇인지
4. 따옴표는 왜 사용하는지
순서대로 설명해주세요.
아직 함수는 배우지 않았으니 어려운 용어는 최소화해주세요.
```

**변수 이름만 개선받기 (구조는 유지)**

```
나는 파이썬 변수 이름을 배우는 초보자야.
아래 코드에서 변수 이름 a, b, c가 너무 모호한 것 같아.
상품 가격, 수량, 총 금액이라는 의미가 드러나도록
snake_case 방식의 변수 이름만 추천해 줘.
코드 구조는 바꾸지 말아 줘.
```

**오류의 원인부터 설명받기**

```
파이썬 초보자야.
아래 코드에서 TypeError가 발생해.
age = 20
print(age + "살")
수정 코드만 주지 말고,
int와 str이 왜 바로 + 될 수 없는지 먼저 설명해 줘.
그다음 내가 이미 배운 str()을 이용한 최소 수정 방법을 알려 줘.
```

**설계 질문만 받고 코드는 아직 요청하지 않기**

```
나는 파이썬을 처음 배우고 있어.
아래 반복 작업을 나중에 파이썬으로 해결해 보고 싶어.
[내가 작성한 입력·처리·출력]
아직 코드는 작성하지 말고,
내가 문제를 더 명확하게 정의하기 위해 생각해야 할 질문을 3개만 만들어 줘.
```

## AI가 만든 코드를 받았을 때 점검하는 4가지

1. **입력** — 어떤 값을 받는가? 어떤 자료형으로 바꾸는가?
2. **처리** — 조건·반복·계산은 무엇인가?
3. **출력** — 무엇을 화면이나 파일에 내보내는가?
4. **낯선 코드** — 아직 배우지 않은 문법·모듈·함수가 섞여 있는가?

## 코드에 문제가 있을 때 디버깅 순서

1. 정상값 / 경계값 / 비정상값을 구분해서 테스트한다.
2. 예상 결과와 실제 결과를 비교해 논리 오류를 찾는다.
3. 문제가 발생한 입력을 기록하고 동일한 상황을 재현할 수 있게 한다.
4. 프로그램 전체가 아니라 **문제가 있는 작은 함수**로 범위를 좁힌다.
5. AI에게는 코드·문제 입력·실제 결과·예상 결과를 **함께** 전달한다.
6. 원인과 관련된 부분만 최소한으로 수정한다 (전체 재작성 지양).
7. 수정 후에는 실패했던 입력뿐 아니라 이전에 정상이었던 값도 다시 테스트한다.
8. 정확성이 확인된 뒤에야 함수/변수 이름, 중복, 복잡성 같은 스타일을 개선한다.
9. AI의 개선 제안도 다시 실행하고 검증한다 — AI의 답변 역시 검증 대상이다.

## 문제를 코드로 옮기기 전에: 요구사항 → 설계 → 구현

- 코드를 작성하기 전에 프로그램의 목적과 범위, 그리고 **"하지 않을 것"** 을 짧은 문장으로 정리한다.
- 프로그램을 입력(Input) → 처리(Process) → 출력(Output)으로 나눈다.
- 사용할 데이터의 모양을 먼저 리스트/딕셔너리로 설계한다.
- 큰 기능을 작은 함수 단위로 나누고, 가장 작은 기능부터 직접 구현해서 실행해본다.
- AI에게는 전체 정답보다 **한 단계 힌트**와 **설계 검토**를 요청한다.

## 과제로 남긴 학습 기록 형식

1. AI가 설명한 내용 중 이해된 것은 무엇인가?
2. 아직 이해되지 않는 것은 무엇인가?
3. 내가 직접 바꾼 코드는 무엇인가?
4. 예상 결과와 실제 결과가 같았는가?

## 오늘 기억할 세 가지

1. AI가 있어도 파이썬 기초는 필요하다 — 코드를 읽고 수정하고 결과를 검증하려면.
2. AI는 정답지가 아니라 **개인 튜터**로 사용한다 — 설명, 힌트, 오류 분석, 검토에 활용.
3. 코드는 직접 실행하고 바꿔봐야 한다 — 그대로 복사하는 것과 직접 검증하며 학습하는 것은 완전히 다르다.
