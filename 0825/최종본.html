오늘은 타이타닉 생존자 데이터를 가지고, 데이터 로딩부터 서비스 배포까지 분석 한 사이클 전체를 AI와 함께 한 번 완주해 보는 실습을 했다. 각 단계를 깊게 파기보다 전체 흐름이 어떻게 이어지는지 보는 것이 목적이었다. 단계마다 더 공부해야 할 것도 함께 적어 둔다.

오늘의 한 줄 정리

  • 분석은 데이터 준비 -> 이해 -> 전처리 -> EDA -> Feature 설계 -> 학습 -> 평가 -> 저장/서비스로 이어지는 하나의 사이클이다.
  • 타이타닉 생존 예측은 정답(생존 여부)이 있으므로 지도학습 문제다.
  • Feature는 많다고 좋은 것이 아니라, 예측에 의미 있는 컬럼을 선별하는 것이 중요하다.

1. 분석 한 사이클의 전체 흐름

타이타닉 생존자 데이터로 아래 흐름을 처음부터 끝까지 한 번 따라가 봤다.

데이터 준비
  -> 데이터 이해
  -> 전처리
  -> 시각화와 EDA
  -> Feature 설계
  -> 학습/테스트 분리
  -> Baseline 모델
  -> 모델 평가
  -> 추가 모델 비교
  -> 최종 모델
  -> 저장과 신규 예측
  -> Streamlit 서비스

2. 머신러닝 학습 방식 3가지

학습 방식 특징
지도학습 (Supervised) 정답(label)이 있는 데이터로 학습
비지도학습 (Unsupervised) 정답 없이 데이터의 구조/패턴을 찾음
강화학습 (Reinforcement) 보상(reward)을 기준으로 행동을 학습

타이타닉 생존 예측은 생존 여부(정답)가 있으므로 지도학습 문제다.

3. 이 사이클에서 실제로 다룬 것들

  • 결측치 처리: 숫자형(age)은 평균, 범주형(embarked)은 최빈값으로 채웠다. 이 기준은 앞선 Pandas 기초 글에서 정리한 내용과 같다.
  • 이상치 확인: fare의 박스 플롯에서 최댓값 512달러를 확인했다.
  • 그룹별 통계: groupby로 생존율을 성별/객실등급별로 비교했다.

4. Feature가 너무 많으면 오히려 성능이 떨어진다

컬럼(피처)이 많으면 오히려 모델의 정확도가 떨어질 수 있다. 분석과 무관하거나 중복된 정보를 담은 컬럼을 무작정 다 넣는 것이 아니라, 예측에 실제로 의미 있는 컬럼을 선별하는 과정(Feature 설계)이 중요하다는 것을 체감했다.

5. 다음에 더 깊이 볼 것

  • Baseline 모델과 이후 모델들의 성능을 비교하는 기준 (정확도만으로 충분한지, 다른 지표가 필요한지)
  • 학습된 모델을 저장하고 새로운 데이터에 대해 예측하는 방법
  • Streamlit으로 분석 결과를 서비스 형태로 배포하는 방법
