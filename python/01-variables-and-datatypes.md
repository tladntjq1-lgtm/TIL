# 변수와 데이터형

## 변수는 이름표다

파이썬에서 변수는 값을 직접 담는 상자가 아니라, 메모리에 생성된 객체를 가리키는 **이름표(참조)** 다.

```python
x = 10
```

위 코드는 `10`이라는 데이터 객체가 먼저 메모리에 생성되고, `x`는 그 객체를 가리키는 이름표 역할을 한다. 변수를 재할당하면 기존 값과의 연결이 끊기고, 이름표를 잃은 데이터는 **가비지 컬렉터(Garbage Collector)** 가 자동으로 메모리에서 정리한다.

## 변수 이름 규칙

- 영문자, 숫자, 밑줄(`_`)을 사용한다.
- 숫자로 시작할 수 없다.
- 공백이나 `-`를 포함할 수 없다.
- `if`, `for`, `class` 같은 예약어는 사용할 수 없다.
- 단어가 여러 개면 `snake_case`를 사용한다 (`student_name`, `total_price`).

```python
# 사용할 수 없는 예
1score        # 숫자로 시작
student-name  # - 사용
total price   # 공백 포함
class         # 예약어
```

의미 없는 이름(`a`, `b`, `c`)을 남용하지 말고 역할이 드러나는 이름을 쓰는 것이 좋다. AI에게 코드를 보여주고 "변수 이름이 모호한데 의미가 드러나게 `snake_case`로 바꿔줘"라고 요청하는 것도 좋은 학습 방법이다.

## 기본 데이터형 4가지

| 타입 | 의미 | 예시 |
|---|---|---|
| `int` | 정수 (소수점 없음) | `20` |
| `float` | 실수 | `175.5` |
| `str` | 문자열 (따옴표로 감싼 글자) | `"문길동"` |
| `bool` | 논리값 (참/거짓) | `True`, `False` |

```python
age = 20
height = 175.5
name = "문길동"
is_student = True

print(type(age))        # <class 'int'>
print(type(height))     # <class 'float'>
print(type(name))       # <class 'str'>
print(type(is_student)) # <class 'bool'>
```

## 형 변환(casting)

`int()`, `float()`, `str()`, `bool()`로 명시적 형 변환을 할 수 있다.

```python
pi = 7.89
print(int(pi))  # 7 (반올림이 아니라 소수점 이하를 버림)
```

정수와 실수를 함께 연산하면 파이썬이 데이터 손실을 막기 위해 정수를 실수 쪽으로 자동 변환한다. 이를 **암묵적 형변환(업캐스팅)** 이라 한다.

변환할 수 없는 값을 억지로 변환하면 `ValueError`가 발생한다.

```python
int("abc")  # ValueError
```

## Falsy 값

명시적으로 `True`/`False`를 쓰지 않아도 "거짓"으로 취급되는 값들이 있다: `0`, 빈 문자열 `""`, 빈 리스트 `[]`, `None` 등. 반대로 요소가 하나라도 채워진 리스트(`[1, 2, 3]`)는 값이 존재하는 상태이므로 참(`True`)으로 취급된다.

## 할당(`=`)과 비교(`==`)는 다르다

```python
age = 20   # 대입연산자: 값을 변수에 대입
age == 20  # 비교연산자: 두 값이 같은지 확인
```

이 둘을 혼동하는 것이 초보 시절 가장 흔한 실수 중 하나다.
