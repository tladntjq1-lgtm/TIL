오늘은 pandas로 표 데이터를 다루는 기본기를 정리했다. DataFrame 구조를 점검하고, 조건으로 행을 거르고, groupby로 집계하고, 결측치와 이상치를 다루는 순서로 이어진다. 코드를 외우기보다 "이 결과가 왜 이렇게 나왔는지"를 설명할 수 있는지에 집중해서 적어 둔다.

오늘의 한 줄 정리

  • 한 열을 고르면 Series, 열을 리스트로 여러 개 고르면 DataFrame이다.
  • 조건식으로 만든 True/False 열(불리언 마스크)로 원하는 행만 남긴다.
  • 건수만 보면 value_counts(), 여러 지표를 함께 보면 groupby() + agg()를 쓴다.
  • 결측치는 숫자형은 평균/중앙값, 범주형은 최빈값으로 채우고, 이상값은 바로 지우지 않고 원인부터 검증한다.

1. Series와 DataFrame

pandas를 설치한 뒤 import pandas as pd로 불러온다.

  • Series: 1차원 데이터 (한 열)
  • DataFrame: 2차원 데이터 (표 전체, 여러 열의 모음)

한 열만 선택하면 Series, 여러 열을 리스트로 선택하면 DataFrame이 된다. 이 차이는 직접 타입을 찍어서 확인해 봐야 한다.

import pandas as pd

df = pd.read_csv("data/orders.csv")

df["price"]           # Series (한 열)
df[["price", "qty"]]  # DataFrame (여러 열)

2. 데이터 구조 점검하기

데이터를 불러오면 분석에 들어가기 전에 먼저 생김새부터 확인한다.

df.head()      # 앞부분 미리보기 (기본 5행)
df.head(10)    # 괄호 안 숫자로 상위 데이터 개수 조절
df.tail()      # 뒷부분 미리보기
df.shape       # (행 수, 열 수)
df.columns     # 열 이름 목록
df.dtypes      # 각 열의 데이터 타입
df.info()      # 구조 전체를 한 번에 확인 (열, 타입, 결측치 개수 등)

3. 불리언 마스크로 행 필터링

비교식을 쓰면 True/False 값으로 이루어진 Series가 만들어지고, 이것을 대괄호에 넣으면 True인 행만 남는다.

customers["age"] >= 30              # 비교식 -> Boolean Series 생성
customers_over_30 = customers[customers["age"] >= 30]  # True인 행만 남음

이렇게 비교식으로 만든 True/False Series를 불리언 마스크라고 부른다. 여러 조건을 조합할 때는 &(and), |(or)와 괄호를 함께 써야 한다.

mask = (customers["age"] >= 30) & (customers["city"] == "서울")
result = customers[mask]

4. 숫자 요약과 결측값 개수

숫자 열은 메서드 하나로 기본 통계를 바로 볼 수 있다.

df["price"].mean()      # 평균
df["price"].min()       # 최솟값
df["price"].max()       # 최댓값
df["price"].sum()       # 합계
df["price"].describe()  # 개수/평균/표준편차/사분위수 등을 한 번에 요약

결측값은 열별로 몇 개인지부터 확인한다.

df.isna().sum()   # 열별로 결측값(NaN) 개수를 확인

5. value_counts와 groupby, agg

value_counts(): 빈도 확인

특정 열의 값들이 각각 몇 번씩 나타나는지 빠르게 확인할 때 쓴다. 주문 상태별(완료/취소/환불 등) 건수를 볼 수 있다.

orders["order_status"].value_counts()
orders["order_status"].value_counts(dropna=False)   # 결측치도 포함해서 보기

품질 점검이 목적이라면 결측치를 포함할지 여부를 의도적으로 결정해야 한다.

value_counts와 groupby/agg 중 무엇을 쓸까

  • 값별 단순 건수만 필요하면 value_counts()
  • 여러 지표(합계, 평균 등)를 함께 봐야 하면 groupby() / agg()

groupby: 같은 카테고리를 한 그룹으로

카테고리가 같으면 한 그룹으로 묶이고, 결과의 한 행은 카테고리 하나를 의미한다.

product_summary = products.groupby("category", as_index=False).agg(
    product_count=("product_id", "nunique"),
    average_price=("price", "mean"),
)
  • agg(): 지표 이름(product_count, average_price)과 계산 함수("nunique", "mean")를 함께 지정한다.
  • as_index=False: 그룹 키(category)를 인덱스가 아니라 일반 컬럼으로 남긴다. 이후 다른 데이터와 저장하거나 병합하기 편해진다.

주의: 같은 category로 groupby를 하더라도, 전체 주문을 기준으로 그룹화했는지 completed 주문만 필터링한 뒤 그룹화했는지에 따라 결과의 의미가 완전히 달라진다. 필터링 순서를 항상 의식해야 한다.

sum()과 mean()

합계와 평균은 서로 다른 질문에 답한다. 결과를 볼 때는 항상 어떤 단위인지를 함께 설명해야 오해가 없다. 예를 들어 "매출 합계"와 "평균 주문 금액"은 완전히 다른 지표다.

6. 문자로 인식된 숫자를 진짜 숫자로 바꾸기

엑셀이나 웹에서 수집한 요금 데이터에 $나 , 같은 기호가 섞여 있으면, 컴퓨터는 이를 숫자가 아닌 문자(Object) 로 인식해서 통계 계산에서 제외해 버린다.

# 1. 기호 제거
df["fare"] = df["fare"].str.replace("$", "").str.replace(",", "")

# 2. 숫자로 강제 변환
df["fare"] = pd.to_numeric(df["fare"])
  • pd.to_numeric(): 통계 계산이 가능한 숫자형으로 강제 변환한다.
  • fillna()는 결측치를 채우는 함수, boxplot()은 시각화 함수, to_string()은 반대로 문자열로 바꾸는 함수라서 이 목적과는 무관하다. 퀴즈에서 자주 헷갈렸던 선택지들이다.

7. 결측치를 채우는 기준

결측치를 채울 때는 데이터 종류에 따라 기준이 달라진다.

데이터 종류 채우는 값 이유
숫자형 (예: 나이) 평균(mean) 또는 중앙값(median) 산술 연산이 가능
문자/범주형 (예: 탑승 항구) 최빈값(mode) 평균을 계산할 수 없음

문자/범주형 데이터는 덧셈과 나눗셈이 불가능해 평균을 구할 수 없다. 그래서 가장 많이 등장하는 값인 최빈값(mode) 으로 채우는 것이 자연스러운 전략이다.

df["embarked"] = df["embarked"].fillna(df["embarked"].mode()[0])
df["age"] = df["age"].fillna(df["age"].mean())

8. Copy-on-Write와 안전한 수정 방법

Pandas 2.2부터 도입된 Copy-on-Write(CoW) 는, 데이터를 조회할 때는 원본을 공유해서 메모리를 아끼다가, 수정(Write)이 발생하는 순간 독립적인 복사본을 만들어 원본을 안전하게 보호하는 메모리 절약 기술이다. SettingWithCopyWarning 같은 문제를 줄여 준다.

  • 권장: .loc[] / .iloc[]로 한 번의 단일 작업에 정확한 위치를 지정해서 수정한다.
  • 비권장: df['A']['B']처럼 대괄호를 연속으로 사용하는 방식. 두 단계로 처리되어 중간에 임시 복사본이 생기고, 원본 수정이 보장되지 않는다.
df.loc[df["age"] > 100, "age"] = None  # 안전한 수정

9. 이상치와 데이터 검증 원칙

다른 데이터에 비해 유독 크거나 작은 값을 이상치(Outlier) 라고 한다. 박스 플롯(Box Plot)을 그리면 상자 바깥에 점으로 표시되어 쉽게 확인할 수 있다.

df["fare"].plot.box()

타이타닉 데이터에서는 fare의 최댓값이 512달러로 나타나 이상치가 있음을 알 수 있었다.

price에 음수가 있거나 age가 1000살로 찍혀 있어도, 바로 삭제하는 것은 잘못된 방법이다. 먼저 이상값의 원인을 검증하고, 검증이 끝난 뒤 필요하다면 마지막 단계에서 처리 방향을 정한다.

10. 에러가 났을 때 체크 순서와 N:M 관계

자주 만나는 오류 체크 순서

  1. ModuleNotFoundError: pandas가 현재 가상환경에 설치되어 있는지
  2. FileNotFoundError: CSV 경로가 맞는지
  3. KeyError: 존재하지 않는 컬럼명을 조회했는지
  4. 자료형 문제: 숫자처럼 보이는 값이 실제로는 문자열(Object)일 수 있음

N:M 관계와 중간 테이블 조인 (도서 대여 예시)

members (1) ── (N) loans (N) ── (1) books
  • 한 사람은 여러 책을 빌릴 수 있다.
  • 착각하기 쉬운 포인트는, 하나의 책도 여러 사람에게 (시간을 두고) 빌려질 수 있다는 것이다. 이것이 N:M 관계다.
  • members, books, loans 세 테이블을 조인해서 "누가 어떤 책을 빌렸는지"를 확인한다.
