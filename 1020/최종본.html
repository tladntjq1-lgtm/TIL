지난번 AI 리터러시 수업에서 환각 현상의 원인(다음 토큰 예측)과 데이터 편향성을 정리했다. 오늘은 환각을 유형별로 구분하는 법과, AI를 쓰는 사람 쪽의 함정인 자동화 편향을 정리한다. 퀴즈에서 틀린 문제는 오답노트로 남겼다.

오늘의 한 줄 정리

  • 환각은 "무엇과 충돌하는가" 로 입력 충돌, 맥락 충돌, 사실 충돌 세 가지로 나눈다.
  • 지식 컷오프는 지어내는 것이 아니라 학습 마감 시점 이후를 애초에 모르는 것이다.
  • 환각은 AI 쪽의 문제이고, 자동화 편향은 사람 쪽의 문제다.

1. 복습: 환각의 근본 원인

LLM은 사실 검증 장치 없이 통계적으로 가장 자연스러운 다음 토큰을 예측해서 문장을 만든다. 그래서 환각은 인터넷 연결 상태나 AI의 "의도"와 무관하게 알고리즘 자체에서 필연적으로 생긴다. AI가 자아를 가졌다거나 일부러 정보를 숨긴다는 설명은 모델을 지나치게 의인화한 오해다.

2. 환각의 3가지 유형

"무엇과 충돌하는가"로 구분하면 헷갈리지 않는다.

유형 충돌하는 대상 예시
입력 충돌 환각 사용자가 입력한 내용 "저는 채식주의자입니다"라고 했는데 고기 요리를 추천
맥락 충돌 환각 AI가 앞에서 직접 생성한 내용 긴 대화나 문서에서 앞서 한 말과 모순되는 내용을 뒤에서 스스로 출력
사실 충돌 환각 실제 세계의 사실 존재하지 않는 논문이나 잘못된 역사적 사실을 지어냄

핵심 구분은 이렇다. 입력 충돌은 "내 말을 무시했다", 맥락 충돌은 "자기가 한 말을 뒤집었다", 사실 충돌은 "현실과 다르다."

3. 지식 컷오프

지식 컷오프(Knowledge Cutoff)는 학습 데이터 수집이 마감된 시점 이후의 사건이나 최신 정보를 모델이 전혀 알지 못하는 현상이다. 거대 모델을 다시 학습시키는 데 드는 비용 때문에 데이터 수집 날짜에서 모델의 지식이 멈춘다.

  • 환각과의 차이: 환각은 "알지 못하는 걸 지어내는 것"이고, 지식 컷오프는 "그 시점 이후의 사실을 애초에 모르는 것"이다. 둘은 서로 다른 개념이다.
  • 보완 방법: 검색 증강 생성(RAG) 기술로 외부 최신 자료를 검색해 참고하게 만든다. 다만 가져온 출처의 신뢰성 문제는 여전히 남는다. 그래서 SIFT 같은 검증이 필요하다.

4. 자동화 편향

자동화 편향(Automation Bias)은 컴퓨터나 AI가 제공하는 정보를, 사람이 자신의 경험적 직관이나 모순된 정보보다 과도하게 신뢰해서 맹목적으로 수용해 버리는 인지적 편향이다.

  • 원인: 인지적 에너지를 아끼려는 뇌의 본능과 AI의 논리 정연한 답변 형식이 결합해서 생긴다.
  • 전문가도 예외가 아니다: 의료진 진단 시뮬레이션 실험에서 전문가 집단조차 이 함정에 빠지는 것이 확인되었다.
  • 장기적 결과: 사람의 능력이 점점 퇴화하는 디스킬링(Deskilling) 을 유발할 수 있다. 이전에 정리한 인지 부채와 같은 맥락이다.
  • 대응 설계: 중요한 판단 단계에 사람이 반드시 개입하는 휴먼 인 더 루프(Human-in-the-Loop) 구조가 중요하다.

5. 오답노트

  • 2번: 입력 충돌과 맥락 충돌을 헷갈렸다. "채식주의자라고 말했는데 고기 추천"은 내가 입력한 말을 무시한 것이라 입력 충돌이다. 맥락 충돌은 AI 자신이 앞에서 쓴 내용과 모순되는 것이다. → "누구의 말과 충돌하나?"를 먼저 물어본다.
  • 3번: 지식 컷오프를 "환각현상"이라고 답했다. "학습 마감 시점 이후를 모른다"는 키워드가 나오면 지식 컷오프다. 환각은 지어내는 것, 컷오프는 모르는 것이다.
  • 5번: 자동화 편향을 "환각현상"이라고 답했다. 환각은 AI 쪽의 문제, 자동화 편향은 사람 쪽의 문제다. "인간이 AI를 과도하게 신뢰"라는 문장이 나오면 자동화 편향이다.
  • 반복되는 패턴: 3번과 5번 모두 "환각현상"으로 답했다. 질문이 AI가 틀리는 이야기인지, 사람이 AI를 믿는 이야기인지 주어가 누구인지 먼저 확인하는 습관이 필요하다.
