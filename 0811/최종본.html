오늘은 파이썬의 가장 밑바닥 내용을 정리했다. 변수가 무엇인지, 어떤 데이터형이 있는지, 연산자와 문자열은 어떻게 다루는지를 한 번에 훑는다. 뒤에 나올 조건문, 함수, 파일 처리가 모두 이 위에 쌓이기 때문에 헷갈리기 쉬운 부분을 표와 그림으로 같이 남겨 둔다.

오늘의 한 줄 정리

  • 파이썬의 변수는 값을 담는 상자가 아니라 객체를 가리키는 이름표(참조) 다.
  • 기본 데이터형은 int, float, str, bool 네 가지이고, 타입이 다른 값끼리 바로 연산하면 TypeError가 난다.
  • /는 정확한 값, //는 몫, %는 나머지다. //와 %를 함께 쓰면 "몫 + 나머지"로 나눌 수 있다.
  • 문자열은 +로 연결하고 *로 반복하며, 인덱싱과 슬라이싱으로 일부를 꺼낸다.

1. 변수는 이름표다

파이썬에서 변수는 값을 직접 담는 상자가 아니라, 메모리에 생성된 객체를 가리키는 이름표(참조) 다.

x = 10

위 코드는 10이라는 데이터 객체가 먼저 메모리에 생성되고, x는 그 객체를 가리키는 이름표 역할을 한다. 변수를 재할당하면 기존 값과의 연결이 끊기고, 이름표를 잃은 데이터는 가비지 컬렉터(Garbage Collector) 가 자동으로 메모리에서 정리한다.

변수 이름 규칙

  • 영문자, 숫자, 밑줄(_)을 사용한다.
  • 숫자로 시작할 수 없다.
  • 공백이나 -를 포함할 수 없다.
  • if, for, class 같은 예약어는 사용할 수 없다.
  • 단어가 여러 개면 snake_case를 사용한다 (student_name, total_price).
# 사용할 수 없는 예
1score        # 숫자로 시작
student-name  # - 사용
total price   # 공백 포함
class         # 예약어

의미 없는 이름(a, b, c)을 남용하지 말고 역할이 드러나는 이름을 쓰는 것이 좋다. AI에게 코드를 보여주고 "변수 이름이 모호한데 의미가 드러나게 snake_case로 바꿔줘"라고 요청하는 것도 좋은 학습 방법이다.

2. 기본 데이터형 4가지와 형 변환

타입 의미 예시
int 정수 (소수점 없음) 20
float 실수 175.5
str 문자열 (따옴표로 감싼 글자) "문길동"
bool 논리값 (참/거짓) True, False 
age = 20
height = 175.5
name = "문길동"
is_student = True

print(type(age))        # <class 'int'>
print(type(height))     # <class 'float'>
print(type(name))       # <class 'str'>
print(type(is_student)) # <class 'bool'>

형 변환(casting)

int(), float(), str(), bool()로 명시적 형 변환을 할 수 있다.

pi = 7.89
print(int(pi))  # 7 (반올림이 아니라 소수점 이하를 버림)

정수와 실수를 함께 연산하면 파이썬이 데이터 손실을 막기 위해 정수를 실수 쪽으로 자동 변환한다. 이를 암묵적 형변환(업캐스팅) 이라 한다.

변환할 수 없는 값을 억지로 변환하면 ValueError가 발생한다.

int("abc")  # ValueError

3. Falsy 값과 할당(=), 비교(==)

Falsy 값

명시적으로 True/False를 쓰지 않아도 "거짓"으로 취급되는 값들이 있다: 0, 빈 문자열 "", 빈 리스트 [], None 등. 반대로 요소가 하나라도 채워진 리스트([1, 2, 3])는 값이 존재하는 상태이므로 참(True)으로 취급된다.

할당(=)과 비교(==)는 다르다

age = 20   # 대입연산자: 값을 변수에 대입
age == 20  # 비교연산자: 두 값이 같은지 확인

이 둘을 혼동하는 것이 초보 시절 가장 흔한 실수 중 하나다.

4. 산술 연산자와 125분 예제

연산자 의미
+ 더하기
- 빼기
* 곱하기
/ 나누기 (실수 나눗셈)
// 몫 (정수 나눗셈)
% 나머지
** 거듭제곱

/, //, %의 차이를 "125분을 시간과 분으로 바꾸기" 예제로 이해하면 명확하다.

minutes = 125

print(minutes / 60)   # 2.0833333333333335 → 정확한 값(소수 포함)
print(minutes // 60)  # 2  → 60이 125 안에 완전히 몇 번 들어가는지 (시간)
print(minutes % 60)   # 5  → 60씩 나누고 남은 나머지 (분)

hours = minutes // 60
remaining_minutes = minutes % 60
print(f"{minutes}분 = {hours}시간 {remaining_minutes}분")  # 125분 = 2시간 5분

//와 %를 함께 쓰면 "몫 + 나머지"로 딱 나눠지는 값을 만들 수 있다.

5. 비교, 논리, 복합 대입 연산자와 타입 에러

비교 연산자와 bool

==, !=, >, <, >=, <=의 비교 결과는 항상 bool(True/False) 타입이다.

논리 연산자

연산자 규칙
and 모두 참일 때만 True (하나라도 False면 진다)
or 하나라도 참이면 True
not 참/거짓을 반대로 바꿈 
age = 20
has_ticket = True

print(age >= 18 and has_ticket)  # True
print(age < 18 or has_ticket)    # True
print(not has_ticket)            # False

복합 대입 연산자

score = 80
score = score + 5   # 같은 표현
score += 5           # 복합 대입 연산자
print(score)         # 85

타입이 다른 값끼리 연산하면 에러가 난다

age = 20
print(age + "살")  # TypeError

int와 str은 서로 다른 타입이라 바로 + 연산이 되지 않는다. str()로 감싸서 age를 문자열로 바꿔주면 해결된다.

print(str(age) + "살")  # "20살"

AI에게 질문할 때도 "수정 코드"만 받지 말고, 왜 안 되는지 원리부터 물어본 뒤 최소한의 수정으로 해결하는 습관을 들이는 것이 좋다.

6. 문자열 연결, 반복, 인덱싱, 슬라이싱

문자열에서는 숫자 계산과 같은 기호(+, *)를 쓰지만 의미가 달라진다.

first = "Hello"
second = "Python"

print(first + second)        # HelloPython (연결)
print(first + " " + second)  # Hello Python
print("Python! " * 3)        # Python! Python! Python!  (반복)
print("-" * 20)              # 구분선 만들기에 자주 사용
  • 문자열 + 문자열 → 연결
  • 문자열 * 정수 → 반복

인덱싱으로 특정 위치의 문자 하나를 가져올 수 있고, 음수 인덱스는 뒤에서부터 센다. 슬라이싱으로 문자열 일부를 잘라낼 수 있다.

text = "Hello Python"
print(text[0])     # H
print(text[-1])    # n (맨 끝 글자)
print(text[0:5])   # Hello
print(text[::-1])  # 전체를 역순으로 뒤집기

7. 자주 쓰는 문자열 메서드와 strip()

메서드 역할
upper() / lower() 대문자 / 소문자 변환
strip() 양 끝 공백(또는 지정 문자) 제거
replace(old, new) 문자열 치환
find() 문자열 위치 검색
count() 등장 횟수 세기
len() 길이 확인

strip() 주의사항: 가운데 문자는 지우지 않는다

text = "   hello world   "
print(text.strip())  # "hello world" ← 앞뒤 공백만 제거, 가운데는 그대로

line = "hello\n"
print(line.strip())  # "hello" ← 줄바꿈 문자도 제거됨 (readline() 결과에서 자주 사용)

text = "***hello***"
print(text.strip("*"))  # "hello" ← 지정한 문자만 양 끝에서 제거

text = "  hi there  "
print(text.lstrip())  # "hi there   " ← 왼쪽 공백만 제거
print(text.rstrip())  # "   hi there" ← 오른쪽 공백만 제거

strip()은 양 끝에서부터만 검사해서 제거하므로, 가운데 있는 공백/문자는 절대 지우지 않는다. input().strip()처럼 사용자 입력값을 다룰 때 자주 쓴다.

8. f-string

f-string은 문자열 안에 변수와 계산식을 직접 넣을 수 있어 가독성이 가장 좋은 문자열 포매팅 방법이다(1세대 % 연산자, 2세대 str.format()보다 발전된 형태).

price = 12000
print(f"{price:>10,}")  # 오른쪽 정렬(>) + 폭 10 + 천단위 콤마(,)

디버깅용 = 연산자는 변수 이름과 값을 동시에 출력해 준다.

score = 95
print(f"{score=}")  # score=95
