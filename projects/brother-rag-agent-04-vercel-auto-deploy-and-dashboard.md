## 배운 것

| 주제 | 배운 점 |
|---|---|
| **Vercel 권한** | Developer 역할은 Production 환경변수와 프로덕션 CLI 배포가 안 된다. 관리자(튜터)에게 **정확히 무엇을 요청할지 목록으로** 정리하면 빠르다 |
| **배포 오류 구분** | **같은 커밋을 같은 설정으로 로컬에서 돌려** 코드 문제인지 환경 문제인지 먼저 나눈다 |
| **로그** | 로그가 잘리면 원인을 못 본다. **오류만 따로 남기되 비밀값은 가린다** |
| **DB 주소 전달** | 비밀번호가 든 DB 주소를 메신저로 보내면 링크로 바뀌면서 `%` 인코딩이 달라질 수 있다. **파일로 전달**한다 |
| **환경변수** | 바꾸면 **Redeploy를 해야** 적용된다 |
| **API 서버 주소** | 브라우저로 열면 `{"detail":"Not Found"}`가 **정상**이다. 화면이 아니라 `/health`, `/agent/invoke`만 있다 |
| **Streamlit 메뉴** | `pages/` 폴더가 있으면 옛 사이드바 메뉴를 자동으로 만든다. 위쪽 메뉴를 쓰려면 **다른 폴더 이름**을 쓴다 |

## 막힌 점과 해결

**빌드 실패 2건**
- 프리셋이 Other라서 함수를 못 찾았다 → `framework: fastapi`로 지정.
- 루트 `requirements`(streamlit 포함)를 설치해서 549MB가 됐다 → **서버용 패키지만 설치**.

**`/agent/invoke` 오류가 3번 이어짐**

| 순서 | 원인 |
|---|---|
| 1 | DB 주소 값 오류 |
| 2 | 비밀번호 인증 실패 |
| 3 | OpenAI 401 |

- 로그로 하나씩 원인을 짚어 튜터에게 **정확히 요청**해서 해결했다.
- **"서버가 DB를 먼저 읽고 OpenAI를 부른다"**는 호출 순서를 이용해, OpenAI 오류 상태에서도 DB가 해결된 것을 따로 확인했다.
