# 결측치, 이상치, 타입 변환

## 문자로 인식된 숫자를 진짜 숫자로 바꾸기

엑셀이나 웹에서 수집한 요금 데이터에 `$`나 `,` 같은 기호가 섞여 있으면, 컴퓨터는 이를 숫자가 아닌 **문자(Object)** 로 인식해 통계 계산에서 제외해버린다.

```python
# 1. 기호 제거
df["fare"] = df["fare"].str.replace("$", "").str.replace(",", "")

# 2. 숫자로 강제 변환
df["fare"] = pd.to_numeric(df["fare"])
```

- `pd.to_numeric()`: 통계 계산이 가능한 숫자형으로 강제 변환.
- `fillna()`는 결측치를 채우는 함수, `boxplot()`은 시각화 함수, `to_string()`은 반대로 문자열로 바꾸는 함수라서 이 목적과는 무관하다. (퀴즈에서 자주 헷갈렸던 선택지들)

## 결측치를 채우는 기준: 숫자형 vs 범주형

| 데이터 종류 | 채우는 값 | 이유 |
|---|---|---|
| 숫자형 (예: 나이) | 평균(mean) 또는 중앙값(median) | 산술 연산이 가능 |
| 문자/범주형 (예: 탑승 항구) | 최빈값(mode) | 평균을 계산할 수 없음 |

문자/범주형 데이터는 덧셈·나눗셈이 불가능해 평균을 구할 수 없으므로, 가장 많이 등장하는 값인 **최빈값(mode)** 으로 결측치를 채우는 것이 자연스러운 전략이다.

```python
df["embarked"] = df["embarked"].fillna(df["embarked"].mode()[0])
df["age"] = df["age"].fillna(df["age"].mean())
```

## Copy-on-Write(CoW)와 안전한 수정 방법

Pandas 2.2부터 도입된 **Copy-on-Write(CoW)** 는, 데이터를 단순히 조회할 때는 원본을 공유해서 메모리를 아끼다가, 수정(Write)이 발생하는 순간 독립적인 복사본을 생성해 원본을 안전하게 보호하는 메모리 절약 기술이다. `SettingWithCopyWarning` 같은 문제를 줄여준다.

- ✅ 권장: `.loc[]` / `.iloc[]`로 **한 번의 단일 작업**에 정확한 위치를 지정해서 수정.
- ❌ 비권장: `df['A']['B']`처럼 대괄호를 **연속으로 사용**하는 방식. 두 단계로 처리되어 중간에 임시 복사본이 생기고, 원본 수정이 보장되지 않는다.

```python
df.loc[df["age"] > 100, "age"] = None  # ✅ 안전
```

## 이상치(Outlier)

다른 데이터에 비해 유독 크거나 작은 값을 **이상치(Outlier)** 라고 한다. 박스 플롯(Box Plot)을 그리면 상자 바깥에 점으로 표시되어 쉽게 확인할 수 있다.

```python
df["fare"].plot.box()
```

타이타닉 데이터에서는 `fare`의 최댓값이 512달러로 나타나 이상치의 존재를 알 수 있었다.

> `price`에 음수가 있거나 `age`가 1000살처럼 비정상적인 값이 보여도, 곧바로 지우는 것이 아니라 원인을 먼저 검증하고, 검증이 끝난 뒤에 처리 방향을 정한다.
