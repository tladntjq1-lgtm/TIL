오늘은 프로그램의 흐름을 만드는 조건문과 반복문, 그리고 코드를 묶어 재사용하는 함수를 정리했다. 조건문은 갈림길, 반복문은 되풀이, 함수는 이름 붙인 코드 덩어리라고 보면 된다. 코드를 바로 치기 전에 수도코드로 생각을 먼저 정리하는 습관도 같이 적어 둔다.

오늘의 한 줄 정리

  • 조건문은 위에서 아래로 평가하다가 처음으로 True가 되는 블록만 실행한다.
  • range()는 끝 값을 포함하지 않는다.
  • break는 반복문 전체를 끝내고, continue는 이번 회차만 건너뛴다.
  • 함수는 print로 보여 주기보다 필요한 값을 return 하는 것이 일반적이다.
  • *args는 튜플, **kwargs는 딕셔너리로 받는다.

1. 조건문 흐름

파이썬은 조건을 위에서 아래로 순차 평가하며 최초로 True가 되는 블록만 실행하고 나머지는 건너뛴다.

score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")   # 여기만 실행되고 즉시 조건문을 탈출
else:
    print("C")

입력을 받아 조건으로 바꿔 쓰는 예:

member_answer = input("회원인가요? (y/n): ").strip().lower()
is_member = member_answer == "y"

2. for문과 range()

for i in range(5):
    print("Python")

for 반복변수 in 반복할값들:
    반복해서 실행할 코드

range()는 끝 값을 포함하지 않는다.

호출 생성되는 값
range(5) 0, 1, 2, 3, 4
range(1, 6) 1, 2, 3, 4, 5
range(2, 11, 2) 2, 4, 6, 8, 10
range(2, 10, 3) 2, 5, 8 (11은 10 이상이라 제외)

반복문에서 값을 누적하는 패턴:

total = 0
for number in range(1, 6):
    total += number

3. while문

while 조건식:
    조건이 참인 동안 반복할 코드

count = 1
while count <= 5:
    print(count)
    count += 1

실행 흐름: count=1 → 조건 확인(True) → 출력 → count += 1 → 조건 재확인 → ... → count=6이 되면 조건이 False가 되어 종료.

break 조건이 없으면 while True:는 무한히 돈다는 점을 항상 의식해야 한다.

4. break와 continue의 차이

  • break: 반복문 전체를 즉시 끝낸다.
  • continue: 현재 회차의 남은 코드만 건너뛰고 다음 반복으로 넘어간다 (반복문 자체는 끝나지 않음).
for number in range(1, 6):
    if number == 3:
        break        # 3에서 반복 전체 종료 → 1, 2 출력
    print(number)

for number in range(1, 6):
    if number == 3:
        continue     # 3만 건너뜀 → 1, 2, 4, 5 출력
    print(number)

문제를 코드로 옮기기 전에: 수도코드

바로 코드를 작성하지 말고, 한글로 수도코드를 먼저 짜는 습관이 중요하다.

문제 → 데이터 → 반복 → 조건 → 결과 → 코드
  • 데이터는 변수에 담는다.
  • 반복문에 들어가는 데이터는 보통 리스트/딕셔너리 형태다.
  • 테이블(표) 형태의 데이터를 담을 그릇이 마땅치 않으면 "리스트 안에 딕셔너리"를 떠올린다.

AI에게 수도코드를 짜달라고 요청하고 직접 구현해 보는 연습도 도움이 된다.

5. 함수 정의와 호출

반복되는 코드를 함수로 묶으면 재사용할 수 있다.

print("안녕하세요!")
print("파이썬 공부를 시작합니다.")

print("안녕하세요!")
print("파이썬 공부를 시작합니다.")

위 코드를 함수로 묶으면:

def greet():
    print("안녕하세요!")
    print("파이썬 공부를 시작합니다.")

greet()
greet()

6. 매개변수와 인수, return

def add(a, b):        # a, b → 매개변수(parameter)
    return a + b

total = add(10, 20)   # 10, 20 → 인수(argument)
print(total)          # 30
  • 10과 20을 인수로 전달 → a, b가 값을 받음 → a + b 계산 → return 30 → total에 30 저장.
  • 함수 안에서는 print를 잘 쓰지 않고, 필요한 값을 return하는 것이 일반적이다. (print는 화면에 보여줄 뿐 값을 반환하지 않는다. split()처럼 값을 반환하는 함수와는 역할이 다르다.)

여러 값 반환 (튜플 언패킹)

함수는 여러 값을 반환하고, 호출하는 쪽에서 튜플 언패킹으로 나눠 받을 수 있다.

def divide(a, b):
    quotient = a // b
    remainder = a % b
    return quotient, remainder

q, r = divide(17, 4)

기본값 매개변수와 키워드 인수

def greet(name, greeting="안녕하세요"):
    print(f"{greeting}, {name}님!")

greet("민수")                     # 기본값 사용
greet("민수", greeting="반갑습니다")  # 키워드 인수로 덮어쓰기

7. 가변 인수와 언패킹

매개변수 앞에 별표 하나(*)를 붙이면, 전달된 여러 인수를 순서대로 묶어 튜플로 처리한다. 별표 두 개(**)는 딕셔너리 구조로 처리된다.

def show_args(*args, **kwargs):
    print(args)    # 튜플
    print(kwargs)  # 딕셔너리

*하나는 튜플, **딕셔너리 — 헷갈릴 때마다 이 문장으로 기억하기.

같은 원리로 언패킹에도 별표를 쓸 수 있다.

x, *rest = (1, 2, 3, 4)
print(x)     # 1
print(rest)  # [2, 3, 4]  ← 별표가 붙은 변수는 원본 자료형과 관계없이 항상 리스트로 담긴다

8. generator와 yield

return은 함수를 완전히 종료시키지만, yield는 값을 반환하면서도 함수의 실행 상태(지역 변수, 실행 위치)를 메모리에 보존한 채 일시 정지한다. 다음 next() 호출 시 그 지점부터 다시 실행된다.

리스트 컴프리헨션([])과 문법이 비슷하지만 소괄호(())를 쓰는 제너레이터 표현식은 결과를 한 번에 메모리에 올리지 않고 필요한 시점에 하나씩 생성해 메모리를 절약한다.

squares = (x * x for x in range(1000000))  # 제너레이터: 메모리 절약

정리와 복습

주제 기억할 것
조건문 위에서 아래로 평가, 처음 True인 블록만 실행
range() 끝 값 제외 (range(1, 6) → 1~5)
while 조건이 False가 되면 종료, break 없는 while True는 무한 반복
break / continue 반복 전체 종료 / 이번 회차만 건너뜀
수도코드 문제 → 데이터 → 반복 → 조건 → 결과 → 코드
매개변수 / 인수 정의할 때 쓰는 이름 / 호출할 때 넘기는 값
return 값을 돌려주고 함수를 끝낸다
*args / **kwargs 튜플 / 딕셔너리
yield 값을 내보내고 실행 상태를 보존한 채 일시 정지
